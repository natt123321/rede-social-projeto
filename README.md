# Projeto Rede Social
**Nome do projeto:** Sistema de Postagens e Comentários
**Equipe de Desenvolvimento:** Natalia Gamero Scognamiglio

## **1. Visão Geral do Sistema (Escopo)**

Um site que seja tipo Instagram, TikTok, um sistema de postagens e comentários.

## **2. Requisitos Funcionais (RF)**

**RF01:** O sistema deve permitir que o usuário crie uma conta.

**RF02:** O sistema deve permitir que o usuário faça uma postagem.

**RF03:** O sistema deve permitir que o usuário edite uma postagem.

**RF04:** O sistema deve permitir que o usuário exclua uma postagem.

**RF05:** O sistema deve permitir que o usuário faça um comentário em uma postagem.

**RF06:** O sistema deve permitir que o usuário edite um comentário.

**RF07:** O sistema deve permitir que o usuário exclua um comentário.

**RF08:** O sistema deve permitir que o usuário visualize as postagens.

**RF09:** O sistema deve permitir que o usuário visualize os comentários de uma postagem.
